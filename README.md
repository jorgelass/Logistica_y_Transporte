# Logistica_y_Transporte

Trabajo de Fin de Grado: Aplicación para gestión de órdenes de carga, especificidades del cliente y entrada de datos de los camioneros mediante Power Apps
Descripción del proyecto
El objetivo de este Trabajo de Fin de Grado es diseñar y desarrollar una solución digital integrada para optimizar la gestión de la información logística y la comunicación interna en el Departamento de Expediciones de la empresa Gonvarri. El proyecto transforma procesos manuales y dispersos en un ecosistema digital centralizado que permite el registro y consulta en tiempo real de datos críticos para la operativa diaria.
La solución se basa en el ecosistema Microsoft Power Platform, utilizando aplicaciones móviles para la gestión operativa y paneles de análisis para la toma de decisiones, garantizando una arquitectura en la nube escalable y eficiente.
Características principales
• Gestión Digital de Órdenes de Carga: Registro centralizado de órdenes previstas mediante entrada manual o captura de imagen con tecnología OCR (Reconocimiento Óptico de Caracteres) para extraer datos automáticamente.
• Gestion de Especificidades: Plataforma para gestionar incidencias, restricciones horarias y condiciones especiales de clientes, sustituyendo la comunicación fragmentada por correo electrónico por una base de datos estructurada.
• Registro Multilingüe de datos de Conductores: Interfaz adaptada a seis idiomas que permite la recogida de datos de camioneros, reutilizando información de viajes anteriores mediante el número de matrícula para agilizar el proceso.
• Automatización y códigos QR: Flujo automatizado con Power Automate que genera códigos QR únicos para la identificación rápida de conductores en la zona de báscula.
• Análisis de Datos en Tiempo Real: Integración con Power BI para la visualización de indicadores clave (KPIs) y el seguimiento de camiones por puerta de carga.
