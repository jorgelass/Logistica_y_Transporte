# 🚛 Logística y Transporte  
### Trabajo de Fin de Grado – Ingeniería Informática  

Aplicación para la gestión digital de órdenes de carga, especificidades de clientes y registro de datos de camioneros mediante **Microsoft Power Apps**.

---

## 📌 Descripción del Proyecto

El objetivo de este Trabajo de Fin de Grado es diseñar y desarrollar una solución digital integrada para optimizar la gestión de la información logística y la comunicación interna en el Departamento de Expediciones de **Gonvarri**.

El proyecto transforma procesos manuales y descentralizados en un ecosistema digital centralizado, permitiendo el registro y consulta en tiempo real de datos críticos para la operativa diaria.

La solución se basa en el ecosistema **Microsoft Power Platform**, combinando aplicaciones móviles para la gestión operativa con herramientas de análisis para la toma de decisiones, garantizando una arquitectura en la nube escalable, segura y eficiente.

---

## 🚀 Características Principales

### 📦 Gestión Digital de Órdenes de Carga
- Registro centralizado de órdenes previstas.
- Introducción manual o captura de imagen mediante tecnología **OCR** (Reconocimiento Óptico de Caracteres).
- Almacenamiento estructurado en SharePoint.

### 📝 Gestión de Especificidades de Clientes
- Registro de incidencias, restricciones horarias y condiciones especiales.
- Sustitución de comunicaciones dispersas por correo electrónico.
- Base de datos estructurada y accesible para distintos departamentos.

### 🌍 Registro Multilingüe de Conductores
- Interfaz disponible en seis idiomas.
- Recuperación automática de datos mediante matrícula.
- Reducción de tiempos y errores en el proceso de registro.

### 🔄 Automatización y Códigos QR
- Flujo automatizado con **Power Automate**.
- Generación de códigos QR únicos para identificación rápida en báscula.
- Comunicación entre aplicaciones en tiempo real.

### 📊 Análisis de Datos en Tiempo Real
- Integración con **Power BI**.
- Visualización de indicadores clave (KPIs).
- Seguimiento de camiones por puerta de carga.
