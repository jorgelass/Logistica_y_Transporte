# FlujosPowerAutomate

Esta carpeta contiene los flujos exportados desde **Power Automate** en formato `.zip`.

## Notas importantes

- Cada archivo `.zip` es la exportación oficial de un flujo, manteniendo toda su estructura, variables y conexiones.
- Para usar un flujo en otra cuenta o entorno, se debe importar el paquete mediante la opción **Importar flujo**.
- Los archivos están comprimidos para **preservar la integridad del flujo**.
- No es necesario descomprimir los `.zip` dentro del repositorio.
